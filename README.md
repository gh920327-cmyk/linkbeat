# 링크비트 (LINKBEAT) — 유튜브 링크로 하는 리듬게임

유튜브 링크를 넣으면 내 PC가 곡을 분석해서 **4키·6키 × 쉬움 / 보통 / 어려움 / 극한** 채보를 자동으로 만들어요.
혼자 하거나, 친구들과 같은 방에서 동시에 플레이해 점수를 겨룰 수 있어요. PC는 키보드, 폰은 터치로 플레이해요.

**주요 기능**: 자동 채보 · 하이라이트(후렴) 감지 · 난이도 별점 · 친구 공용 순위표 · 피버 · 미러/랜덤 · 하이라이트 모드 · 연습 모드 · 타이밍 분석 · 싱크 자동 맞추기 · 곡 미리듣기 · 곡 신청함 · 실시간 멀티 · 채보 수정기

---

## 0. 서울 서버 + PC 실행기 (서버를 안 켜도 언제든 플레이)

게임 서버는 달 없는 밤과 같은 **서울 서버**에서 24시간 돌아가요. 친구들은 **LINKBEAT 실행기**(exe)만 깔면 언제든 접속해요.
곡을 새로 만드는 일(유튜브 음원 받기 + 채보 분석)만 **호스트 PC**의 실행기가 맡아요. 유튜브가 클라우드 서버의 음원 받기를 막기 때문이에요.

### 서버 설치 (처음 한 번, 호스트)
1. AWS 라이트세일 → 달 없는 밤 서버 → **브라우저 SSH** 열기
2. 아래 한 줄을 붙여넣고 Enter:
   ```
   curl -fsSL https://raw.githubusercontent.com/gh920327-cmyk/linkbeat/main/deploy/setup.sh | sudo bash
   ```
3. 끝나면 **게임 주소**와 **호스트 키**가 나와요. 호스트 키는 본인만 쓰고 친구에게 알려주지 마세요.
   (잊어버리면 `sudo grep KEY /etc/linkbeat.env`)
- 달 없는 밤은 그대로 돌아가요. 주소만 따로예요 (`https://linkbeat.<서버IP>.sslip.io`).
- 깃허브에 새 코드가 올라오면 서버가 1분 안에 받아요. 단, **방에 친구들이 있으면(플레이 중) 기다렸다가** 아무도 없을 때 적용해요.
- 곡·기록·프로필은 매일 새벽 5시에 서버 안에 백업돼요 (최근 14일치, `/var/backups/linkbeat`).

### 실행기 (모두)
- 받기: https://github.com/gh920327-cmyk/linkbeat/releases/latest/download/LINKBEAT-Setup.exe
  (웹 브라우저로 접속해도 플레이할 수 있어요. 설정 창의 'PC 실행기 받기'로도 받을 수 있어요)
- 켜면 **시작 화면 → 로그인(아이디 + 숫자 비밀번호)** 후 게임에 들어가요. 처음이면 '새로 만들기'.
- 실행기는 새 버전이 나오면 자동으로 업데이트돼요.

### 호스트 PC (곡 추가)
1. 실행기 → 로그인 → **설정 → 호스트 키** 칸에 서버 설치 때 받은 키를 넣어요.
2. 처음 한 번 '채보 엔진'이 설치돼요 (몇 분). 파이썬이 없으면 설치를 도와줘요.
3. 이제 곡 목록 위의 칸에 유튜브 링크를 넣으면 **대기열**에 들어가고, 실행기가 채보를 만들어 서버에 올려요.
   - 서버는 꺼지지 않아요. 플레이 중인 친구도 끊기지 않고, 완성되면 곡 목록에 바로 나타나요.
   - 실행기가 꺼져 있으면 '채보 PC 꺼짐 · 대기 N곡'으로 남아 있다가, 실행기를 켜면 차례로 만들어져요.
4. **친구 신청은 승인한 것만** 곡이 돼요. 신청은 한 사람(같은 인터넷)당 10분에 5곡까지예요.
5. 예전에 PC에서 쓰던 곡·기록·프로필은 **'PC 데이터 옮기기'** 버튼으로 한 번에 서버로 옮겨요 (start.bat 이 있던 폴더를 고르면 돼요).

## 1. 처음 설치 (한 번만)

1. **파이썬 설치**: https://www.python.org/downloads/ 에서 받아 설치하세요.
   설치 첫 화면에서 **"Add python.exe to PATH"** 를 꼭 체크하세요.
2. 이 폴더를 원하는 곳(예: `E:\linkbeat`)에 압축 해제하세요.
3. **`start.bat`** 을 더블클릭하세요.
   첫 실행 때는 필요한 프로그램을 자동으로 설치해요. 몇 분 정도 걸려요.
4. 설치가 끝나면 브라우저가 자동으로 열려요. 이 창이 **호스트(관리자) 화면**이에요.

> 다음부터는 `start.bat` 만 실행하면 돼요. 검은 서버 창을 닫으면 게임도 꺼져요.

## 2. 곡 추가하기 (호스트만)

1. 로비 맨 위 입력칸에 유튜브 링크를 붙여넣고 **채보 만들기**를 누르세요.
2. "오디오 받는 중 → 리듬 분석 중 → 완료" 순서로 진행돼요. 보통 10~40초 걸려요.
3. 곡 목록에 나타나면 바로 플레이할 수 있어요.

- 받은 오디오는 분석에만 쓰고 **바로 삭제**돼요. 남는 건 채보 파일(`data/songs/`)뿐이에요.
- 게임할 때 음악은 화면 안의 **유튜브 플레이어**로 나와요.
- **"다른 사이트에서 재생이 막혀 있어요"** 라고 나오면, 그 영상은 퍼가기가 금지된 영상이에요.
  같은 곡의 가사 영상이나 다른 업로드를 찾아서 넣어 주세요. 일부 공식 뮤직비디오가 이런 경우가 많아요.
- 곡 추가가 갑자기 안 되면, 유튜브가 바뀐 경우가 많아요. `start.bat` 을 다시 실행하면
  다운로더(yt-dlp)가 자동으로 최신 버전으로 업데이트돼요.

---

### 친구가 곡을 신청하려면
친구 화면 위쪽 **곡 신청** 칸에 유튜브 링크를 붙여넣으면, 호스트 화면의 **곡 신청함**에 제목과 함께 바로 떠요(알림도 와요).
호스트가 **승인**을 누르면 채보가 만들어져서 모두의 곡 목록에 자동으로 나타나고, **거절**하면 지워져요.

## 3. 플레이 방법

### 곡 선택 화면
곡 목록 위 정렬 칸에서 **최근 추가 / 제목순 / 가수순 / 많이 플레이 / 별점순** 등을 고를 수 있고, 검색 칸은 곡 제목과 가수 이름을 함께 찾아요.
- 곡 제목 아래 회색 글씨는 **부른 가수**예요. 유튜브 음악 정보 → 영상 제목("[MV] 가수 _ 곡" 같은 형식) → 채널 이름 → 애플 음악 검색 순으로 찾아요(소속사·가사 채널은 제외). "곡 - 가수"인지 "가수 - 곡"인지 헷갈리는 제목은 음악 검색과 말투(띄어쓰기·조사)로 가려내요.
- 틀렸으면 방장은 가수 옆 **✎** 버튼으로 제목·가수를 고칠 수 있어요. 직접 고친 가수는 채보를 다시 만들어도 유지돼요.
- ✎로 고치면 **배워요**: 그 가수 이름을 기억하고, 그 채널이 '가수 - 곡' / '곡 - 가수' 중 어느 순서로 올리는지도 기억해서 같은 채널·같은 가수의 다른 곡들도 바로 다시 맞춰요. (배운 내용은 data/artist_learn.json)
- "cover by 누구" 커버 영상은 실제로 부른 사람, "(가사 한 줄) : 가수 - 곡" 형식은 ':' 뒤만 보고, "곡(원제)"처럼 괄호에 원제가 붙은 쪽은 곡 제목으로 봐요.
- 같은 가수가 "바운디 / Vaundy", "아이유 / IU(아이유)"처럼 다르게 적혀 있으면 발음과 괄호 병기를 보고 하나로 묶어서, 더 많이 쓰인 이름으로 통일해 보여줘요. 원하는 표기가 있으면 그 가수 곡 하나를 ✎로 고치면 같은 가수 곡이 전부 그 이름으로 바뀌어요.
- 예전에 추가한 곡은 서버를 켤 때 뒤에서 유튜브 정보를 다시 확인해 가수를 채워요(오디오는 받지 않아요).

| 키 | 기능 |
|---|---|
| **↑ ↓** | 곡 고르기 (고르면 왼쪽 썸네일 자리에서 미리듣기가 나와요) |
| **← →** | 난이도 (쉬움 / 보통 / 어려움 / 극한) |
| **Tab** | 4키 ↔ 6키 |
| **Enter** | 시작 (곡을 더블클릭해도 돼요) |

미리듣기가 자동으로 나오는 게 싫으면 설정 → "곡 선택 시 미리듣기"를 "버튼 누를 때만"으로 바꾸세요.

### 플레이 중
| 키 | 기능 |
|---|---|
| **D F J K** | 4키 레인 |
| **S D F J K L** | 6키 레인 (둘 다 설정에서 변경 가능) |
| **ESC** | 일시정지 / 나가기 |
| **-** / **=** | 싱크 조절 (5ms씩) |
| **↑** / **↓** | 노트 속도 조절 (0.5씩) |

**키 바꾸기**: 설정(또는 곡 선택 화면 조작법의 "키 바꾸기")에서 4키·6키 레인과 일시정지·싱크·속도 키를 모두 바꿀 수 있어요.
칸을 누르고 원하는 키를 누르면 돼요(ESC는 취소). 이미 쓰는 키를 고르면 두 키가 자동으로 맞바뀌어서 겹치지 않아요.
"키 기본값으로" 버튼으로 언제든 처음 상태로 돌아갈 수 있어요. 키 설정은 브라우저마다 따로 저장돼요.

**폰으로 할 때**: 레인을 손가락으로 탭하세요. 시작할 때 "탭해서 시작"을 한 번 눌러야 소리가 나와요.
오른쪽 위 ❚❚ 버튼이 일시정지예요. 화면이 세로로 긴 폰에서도 플레이할 수 있어요.

- 노트가 판정선에 닿을 때 누르세요. 긴 노트는 끝까지 누르고 있어야 해요.
- 판정 범위: PERFECT ±45ms · GREAT ±90ms · GOOD ±140ms
- **소리와 노트가 안 맞을 때**: 설정 → **🎯 싱크 자동 맞추기**를 써 보세요.
  곡을 하나 고르고, 노래의 강한 박(쿵)에 맞춰 키를 32번 누르면 알맞은 값을 계산해서 적용해 줘요.
  플레이 중 **=** (플러스) / **-** (마이너스)로 직접 조절할 수도 있어요. 블루투스 이어폰은 보통 +100~200ms 정도 필요해요.

### 꾸미기 (상단 "꾸미기" 버튼)
바꾸는 즉시 왼쪽 미리보기 기어에 반영되고, 사람마다(브라우저마다) 따로 저장돼요.
- **레인 색**: 클래식 · 네온 · 선셋 · 민트 · 모노 · 커스텀(색 직접 고르기)
- **노트**: 막대 · 둥근 캡슐 · 원형 · 얇은 선, 두께 조절
- **기어**: 레인 폭, 기어 위치(왼쪽/가운데/오른쪽), 판정선 색과 높이
- **효과·소리**: 타격 이펙트(플래시/링/불꽃/끄기), **타격감 세기**(약하게/보통/강하게 — 키 빔·노트 폭발·파편·판정선 펄스·기어 반동), **화면 흔들림** 켜기/끄기, 타격음 14종(클릭·부드러운 톡·드럼·킥·스네어·하이햇·림샷·박수·우드블록·뽁·8비트·코인·레이저·벨 — 모두 직접 합성한 소리, 끄기 가능), 음량. 타격음은 **설정** 창에서도 바로 고르고 들어볼 수 있어요.
- **표시**: 판정 글자 크기, 빠름·느림 표시, 콤보 숫자, 피버 연출 켜고 끄기

### 내 캐릭터 (상단 "내 캐릭터" 버튼)
피부, 머리 모양(5종)·색, 눈(4종), 옷(3종)·색, 액세서리(헤드폰/모자/리본/고양이 귀/안경)를 골라 나만의 도트 캐릭터를 만들어요. 🎲 랜덤도 있어요.
- 플레이 중에는 오른쪽 칸에서 박자에 맞춰 까딱이고, 노트를 칠 때마다 팔을 흔들어요. 콤보 50마다 점프, 피버 때 춤, 미스 나면 시무룩해져요.
- 결과 화면에서는 등급에 따라 환호하거나 아쉬워해요.
- 멀티에서는 방 인원 목록, 실시간 순위, 결과에 친구들의 캐릭터도 보여요.

### 풀콤보 박수
미스 없이 끝까지 치면(**FULL COMBO**) 마지막 노트를 치는 순간 기어 한가운데 글자와 함께 **박수**가 터지고, 결과 화면에 꽃가루가 떨어져요.
전부 PERFECT(**ALL PERFECT**)면 더 많은 사람이 더 오래 박수 치고 환호 휘파람도 나와요. 하이라이트 모드·멀티에서도 나오고, 연습 모드에선 안 나와요.
꾸미기 → 효과·소리 → '풀콤보 박수'로 끄거나 미리 들어볼 수 있어요. (소리 크기는 게임 음량을 따라가요)

### 피버
좋은 판정이 이어지면 기어 오른쪽 게이지가 차요. 가득 차면 **FEVER x2**가 되고, 8초 안에 다시 채우면 x3 → x4 → x5까지 올라가요.
미스가 나면 게이지와 배율이 초기화돼요. 점수는 **정확도 90만 + 피버 보너스 10만**이라, 전부 PERFECT면 100만 점이에요.

### 옵션 (곡 선택 화면)
- **MIRROR**: 노트 배치를 좌우로 뒤집어요.
- **RANDOM**: 레인을 섞어요. 판마다 달라져요.
- 옵션을 켜도 순위표에 기록돼요. 결과 화면에 어떤 옵션을 썼는지 표시돼요.
- **HIGHLIGHT (후렴만)**: 곡에서 가장 잘 들리는 부분(대개 후렴)만 15~40초 짧게 플레이해요. 칩 옆에 구간(예: 0:45~1:05)이 보여요.
  한 마디 앞에서 음악이 먼저 나오고, 노트는 후렴이 시작될 때부터 나와요. **기록과 순위표는 전체곡과 따로** 저장돼요(순위표의 '하이라이트' 탭).

### 하이라이트(후렴) 감지
채보를 만들 때 곡 전체를 분석해서 **가장 잘 들리는 구간**을 찾아요.
- 같은 화음·멜로디가 곡 안에서 다시 나오는지(반복), 소리가 크고 촘촘한지(에너지), 목소리가 크고 높은지를 합쳐 점수를 매겨요.
- 구간이 바뀌는 지점과 마디 첫 박에 맞춰 시작해서, 후렴이 시작되는 박에 딱 맞게 잘라요.
- 이렇게 찾은 구간은 **미리듣기 시작 위치**(곡을 고르면 후렴부터 들려요), **하이라이트 모드**, **연습 모드 기본 구간**에 쓰여요.
- 플레이 중 후렴에 들어가면 **HIGHLIGHT** 글자와 함께 빛이 쓸어 올라가고, 후렴 동안 기어 양옆이 박자에 맞춰 금빛으로 빛나요. (꾸미기 → 표시 → '후렴 연출'로 끌 수 있어요)
- 예전에 만든 곡은 노트가 가장 몰린 구간으로 어림해 둬요. **↻ 전체 채보 다시 만들기**를 하면 음원 분석으로 정확해져요.

### 연습 모드
곡 선택 화면의 **연습** 버튼을 누르고 구간(시작~끝), 속도(0.5/0.75/1배), 반복 여부를 고르세요.
반복을 켜면 구간이 끝날 때마다 정확도를 알려주고 다시 시작해요. 끝내려면 ESC → 나가기. 연습 기록은 순위표에 남지 않아요.

### 결과 화면 타이밍 분석
판정이 빠르게 났는지 느리게 났는지 그래프로 보여줘요. 한쪽으로 10ms 이상 치우쳐 있으면
"싱크를 ○○ms로 바꾸면 좋아요"와 **적용** 버튼이 나와요. 몇 판 하다 보면 내 환경에 딱 맞는 싱크가 잡혀요.

### 난이도 별점 (★)
채보 자체를 분석해서 객관적으로 매긴 점수예요. 가장 바쁜 구간의 초당 노트 수를 기본으로,
같은 키 연타·동시치기·긴 노트를 누른 채 치는 패턴이 많을수록 높아져요. 6키는 조금 더 높게 나와요.

| 별점 | 대략 |
|---|---|
| ★1~2 | 입문 |
| ★3~4 | 보통 |
| ★5~6 | 어려움 |
| ★7~8 | 고수 (극한) |
| ★8.5 이상 | 초고수 (보라색) |

### 자동 채보가 소리를 고르는 방식
- **목소리가 가장 먼저:** 음원을 스테레오로 받아 '가운데에 있으면서 음높이가 있는 소리'(보컬)를 따로 찾아요. 새 음절이 시작되는 순간과, 끊지 않고 이어 부르며 음이 바뀌는 순간을 노트로 만들고, 목소리 음높이가 올라가면 오른쪽, 내려가면 왼쪽 레인으로 가요.
- **그다음 드럼:** 킥·스네어를 따로 찾아 노트로 만들어요. 왼쪽·오른쪽으로 벌린 기타·패드, 하이햇은 덜 중요하게 봐요.
- **보컬이 쉬면 악기 멜로디:** 순간마다 목소리와 악기 중 어느 쪽이 더 잘 들리는지 비교해서, 간주처럼 노래가 쉬는 구간에서는 기타 리드·신스 같은 악기 멜로디가 노트의 주인공이 돼요. (작게 깔린 패드나 하이햇은 빼요)
- **후렴 강조:** 후렴(하이라이트)은 조금 더 꽉 찬 채보가 되고, 후렴이 시작되는 박은 강타 노트가 돼요.
- **드럼 강타:** 심벌과 함께 '탁' 치는 박처럼 주변보다 확 튀는 타격은 금빛 테두리의 **강타 노트**(보통·어려움 2개, 극한 3개 동시치기)가 되고, 치면 크게 터지고 화면이 번쩍여요. 드럼 필인은 어려움 이상에서 계단처럼 흐르는 노트가 돼요.
소리를 **저음(킥·베이스) / 중음(스네어·보컬·기타) / 고음(하이햇·신스·고음 멜로디)** 으로 나눠서 대역마다 리듬을 따로 찾아요.
그래서 베이스만이 아니라 작은 고음 소리도 노트가 되고, 레인은 음높이를 따라가요(저음은 왼쪽, 고음은 오른쪽 경향).
**극한**은 작은 장식음까지 잡아서 더 촘촘하고, 동시치기·긴 노트도 많아요.
예전에 추가한 곡은 어려움 채보를 바탕으로 극한을 자동으로 만들어 두었어요. 채보 수정기의 **자동 채보 다시 만들기**를 하면 새 분석 방식으로 전부 다시 만들어져요.
- **구간 분석:** 후렴처럼 신나는 구간은 노트·동시치기가 많아지고, 인트로나 조용한 구간은 차분해져요(리듬은 살아 있어요).
- **템포 변화:** 박자를 구간마다 다시 추정해서, 중간에 빨라지거나 느려지는 곡도 박자를 따라가요. 플레이 화면의 마디선도 실제 박에 맞춰져요.

### 순위표
플레이가 끝나면 점수가 서버(호스트 PC)에 자동으로 저장돼요. **닉네임 기준**으로 곡·키·난이도마다 최고 기록이 남아요.
곡 선택 화면에 친구 1위와 내 기록이 보이고, **순위표** 버튼으로 전체 순위를 볼 수 있어요.
닉네임을 먼저 정해 두세요. (비워두면 "이름없음"으로 저장돼요)

## 4. 친구와 함께하기

### 방 만들기
1. 로비 오른쪽 **방 만들기**를 누르면 4글자 방 코드가 나와요.
2. 친구가 접속해서 코드를 입력하고 **참가**를 누르면 돼요. 최대 8명까지 들어올 수 있어요.
3. 방장은 곡을 고르고 **이 곡으로** → **게임 시작**을 누르세요.
4. 방장이 **HIGHLIGHT** 칩을 켜면 방 전체가 하이라이트 모드(후렴만)로 플레이해요. 친구 화면의 방 정보에 "하이라이트 모드"와 구간이 표시돼요.
5. **난이도와 4키/6키는 각자 골라요.** 로비에서 난이도 칸이나 4KEY/6KEY 탭을 바꾸면 방 인원 목록에 바로 보여요. 같은 곡을 서로 다른 난이도로 함께 할 수 있어요.
6. 모두 영상 로딩이 끝나면 동시에 카운트다운이 시작돼요.
7. 플레이 중에는 오른쪽에 **친구 화면**(친구들의 기어가 작게 실시간으로 움직여요)과 실시간 순위가 보여요. 결과에는 각자의 난이도도 함께 나와요.

### 프로필 (주소가 바뀌어도 기록·설정 유지)
친구 초대 주소(share.bat)는 켤 때마다 바뀌고, 브라우저는 주소마다 저장소가 따로라서 친구 쪽은 매번 처음 상태가 돼요.
상단 **☁ 프로필** 버튼에서 아이디와 숫자 비밀번호(4~8자리)로 프로필을 만들어 두세요.
- 이름·키 설정·꾸미기·캐릭터·싱크·속도·내 기록이 방장 PC 서버(`data/profiles.json`)에 자동 저장돼요.
- 새 주소로 들어오면 위쪽에 안내가 떠요. **프로필 불러오기**로 아이디와 비밀번호를 넣으면 전부 돌아와요.
- 비밀번호는 암호화(해시)해서 저장해요. 5번 틀리면 1분 동안 막혀요. 실제로 쓰는 비밀번호 말고 게임용 숫자를 쓰세요.
- 방장은 항상 같은 주소(localhost)라서 프로필 없이도 유지돼요.

### 친구가 접속하는 방법

**같은 와이파이(같은 집)라면**
서버 창에 나오는 `http://192.168.x.x:8800` 주소로 접속하면 돼요.
(윈도우 방화벽 허용 창이 뜨면 "허용"을 눌러 주세요.)

**인터넷으로 멀리 있는 친구라면 (추천: share.bat)**
1. `start.bat` 으로 서버를 켠 상태에서 **`share.bat`** 을 실행하세요.
2. 처음이면 `cloudflared` 설치를 물어봐요. 설치한 뒤 `share.bat` 을 다시 실행하세요.
3. 창에 `https://어쩌구.trycloudflare.com` 주소가 나오면 그 주소를 친구에게 보내세요.
   - 주소는 실행할 때마다 바뀌어요.
   - 서버 창과 share 창을 모두 켜둬야 해요.
   - 주소를 아는 사람은 누구나 들어올 수 있으니 믿을 만한 친구에게만 보내세요.
     (곡 추가·수정·삭제는 호스트만 할 수 있어요.)

**playit.gg 를 쓰고 싶다면**
playit.gg에서 **TCP 터널**을 만들고 로컬 포트를 **8800**으로 지정하세요.
친구는 `http://터널주소:포트` 로 접속하면 돼요.

> 호스트는 항상 **내 PC의 `http://localhost:8800`** 으로 접속해야 곡 추가·수정을 할 수 있어요.
> 공유 주소로 접속하면 일반 플레이어로 보여요.

## 5. 채보 수정하기 (호스트만)

곡을 고르고 **수정** 버튼을 누르면 수정 화면이 열려요. (PC의 넓은 화면에서만 열려요)
위쪽 **키** 칸에서 4키/6키 채보를 골라 고칠 수 있고, 고치는 대로 별점이 바로 다시 계산돼요.

| 조작 | 기능 |
|---|---|
| 빈 곳 클릭 | 노트 추가 |
| 클릭한 채로 위로 드래그 | 긴 노트 |
| 노트 드래그 | 이동 |
| 우클릭 | 삭제 |
| 마우스 휠 / Ctrl+휠 | 시간 이동 / 확대·축소 |
| ← → | 한 칸씩 이동 |
| Space | 재생 / 정지 |
| R | 녹화 모드 (재생하며 D F J K를 누르면 노트가 찍혀요. 길게 누르면 긴 노트) |
| Ctrl+Z / Ctrl+S | 되돌리기 / 저장 |

- **스냅**: 노트가 박자 격자에 맞춰 붙어요. 1/4박이 기본이에요. "자유"로 바꾸면 격자 없이 찍혀요.
- **재생 속도**를 0.5배로 낮추면 빠른 곡도 정확하게 녹화할 수 있어요.
- 격자가 박자와 안 맞으면 **BPM**과 **첫 박 위치**를 고쳐 보세요.
- **이 채보로 플레이**로 바로 테스트해 볼 수 있어요. 테스트 기록은 최고 기록에 남지 않아요.
- 더보기 → **자동 채보 다시 만들기**는 4키·6키 모든 난이도를 처음 상태로 되돌려요.
- **전체 채보 다시 만들기**(곡 추가 칸 아래 버튼): 모든 곡을 최신 분석 방식으로 한 번에 다시 만들어요. 한 곡씩 차례로 진행되고 진행 막대와 **멈추기** 버튼이 보여요.
  직접 고친 난이도와 바꿔둔 곡 제목은 그대로 두고, 받을 수 없는 영상은 기존 채보를 유지한 채 건너뛰어요. (곡당 20~30초 정도)
- 이번 업데이트에서 **긴 노트 생성 방식**이 좋아졌어요(보통·쉬움에도 길게 이어지는 음에 긴 노트가 나와요).
  예전에 만든 곡에 반영하려면 이 버튼으로 다시 만들어 주세요.
- 6키가 생기기 전에 만든 곡은 4키 채보를 6키로 자동 변환해 둬요. 다시 만들면 6키 전용 채보가 생겨요.

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| `start.bat` 이 "파이썬이 없어요" | 파이썬 설치 시 "Add python.exe to PATH" 체크 후 재설치 |
| 설치 중 오류 | 인터넷 확인 후 `.venv` 폴더를 지우고 `start.bat` 다시 실행 |
| 곡 추가 시 "영상을 받을 수 없어요" | `start.bat` 다시 실행 (yt-dlp 자동 업데이트). 그래도 안 되면 다른 영상으로 |
| 화면은 나오는데 영상이 안 나옴 | 인터넷 연결 확인, 브라우저 광고 차단 확장을 이 주소에서 끄기 |
| 친구가 접속 못 함 | 서버 창과 share 창이 켜져 있는지, 주소를 정확히 보냈는지 확인 |
| 노트와 소리가 안 맞음 | 플레이 중 **-** / **=** 로 싱크 조절 |
| 8800 포트를 이미 사용 중 | 링크비트가 이미 켜져 있는지 확인 |

## 폴더 구성

```
start.bat          서버 실행 (처음엔 자동 설치)
share.bat          친구 초대 주소 만들기 (cloudflared)
server.py          게임 서버 (곡 관리 + 멀티플레이)
chartgen.py        자동 채보 생성기 (리듬 분석)
artist.py          부른 가수 찾기 (유튜브 정보·제목·채널)
static/            게임 화면
data/songs/        만들어진 채보 (곡마다 json 파일 1개)
data/scores/       순위표와 플레이 횟수 (곡마다 json 파일 1개)
data/requests.json 친구들의 곡 신청 목록
data/host_key.txt  호스트 인증 키 (다른 사람에게 보여주지 마세요)
```

개인적으로 즐기기 위한 비상업용 프로젝트예요. 곡의 저작권은 각 원작자에게 있어요.
